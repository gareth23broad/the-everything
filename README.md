# The Everything

A calm puzzle-and-build game. Solve one-per-colour logic puzzles (shells in Seaside, flowers in Spring Garden) to earn pearls, spend pearls on the wheel to build islands, and clear the mist to open each new island.

Islands so far: The Lighthouse (Seaside) and The Greenhouse (Spring Garden).

Play: https://gareth23broad.github.io/the-everything/
